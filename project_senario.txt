Food Recipe Blog Project
Technologies Used:

Frontend: HTML, CSS, Bootstrap, JavaScript
Backend: Node.js, Express.js
Database: MongoDB
Project Overview:
The Food Recipe Blog is a comprehensive web application designed to manage and display recipes. The project features three distinct panels: Admin Panel, User Admin Panel, and User Panel, each with unique functionalities.

1. Admin Panel:

Recipe Management: Admins can add, update, and delete recipes. Each recipe includes an image upload feature.
User Recipes: Admins can view recipes added by users, displayed along with the user's name and email.
2. User Admin Panel:

Recipe Management: Users can add, update, and delete their recipes. Similar to the admin, users can upload images for their recipes.
Recipe Visibility: Recipes added by users are visible in the Admin Panel, with the user's details.
3. User Panel:

Recipe Viewing: Users can browse recipes without logging in. Both admin and user-added recipes are displayed, with attribution (e.g., "Added by Admin" or "Added by [User's Name]").
Category Browsing: The homepage features categories such as American, Indian, Thai, Chinese, and Mexican. Clicking on a category shows only recipes from that category.
Recipe Details: Each recipe page displays the recipe image, description, ingredients, and a review section.
Review System: Users can leave reviews by entering their name, rating, review, and email. Upon submission, a verification link is sent to the entered email. Clicking the verification link redirects the user back to the recipe page to confirm and submit the review. Ratings are displayed in a star format.
Search Functionality: Users can search for recipes by name or category from the homepage and category pages.
Additional Features:

Random Recipe: A feature on the homepage that displays a random recipe. Refreshing the page changes the displayed recipe.
Latest Recipes: Shows the latest 20 recipes added, regardless of category.
Category Highlights: The homepage also displays the latest 5 recipes from select categories, allowing quick access without navigating to the category section.
